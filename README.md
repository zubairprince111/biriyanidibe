# Biriyani Map Live

This project is a React application built with Vite, TypeScript, shadcn-ui, and Tailwind CSS.

## Getting Started

To get started with the project properly, follow these steps:

1.  **Clone the repository:**

    ```sh
    git clone <YOUR_GIT_URL>
    cd biriyani-map-live
    ```

2.  **Install dependencies:**

    ```sh
    npm install
    ```

3.  **Start the development server:**

    ```sh
    npm run dev
    ```

## Technologies Used

-   [Vite](https://vitejs.dev/)
-   [React](https://react.dev/)
-   [TypeScript](https://www.typescriptlang.org/)
-   [shadcn-ui](https://ui.shadcn.com/)
-   [Tailwind CSS](https://tailwindcss.com/)
-   [Supabase](https://supabase.com/)
-   [React Leaflet](https://react-leaflet.js.org/)

## Features

-   Interactive map showing Biriyani spots.
-   User authentication.
-   Review and rating system.
